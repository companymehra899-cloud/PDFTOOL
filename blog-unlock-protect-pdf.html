How to Unlock or Protect a PDF

Need to open a password-protected PDF you created, or keep a sensitive file safe before sending? Here is how to unlock and protect PDFs free — in your browser.

By ePDFConverter Team · September 3, 2026 · 7 min read

In this guide

  • Two kinds of PDF protection
  • Removing a password you own
  • Adding password protection
  • Only unlock what you own
  • Frequently asked questions

Two kinds of PDF protection

PDFs can be protected in two ways. Open protection requires a password to open the file at all. Permission protection restricts what you can do once it is open — printing, copying text or editing. The tools below let you both remove protection you own and add it to your own files.

Removing a password you own

If you set a password on a PDF and have forgotten it, or you have a file you are authorised to open and want to remove the password from, the Unlock PDF tool handles it:

  1. Open the tool. Go to Unlock / Protect PDF.
  2. Upload the PDF. Drop it in or click to browse.
  3. Enter the password. Type the open password to decrypt the file.
  4. Download the unlocked copy. The new file opens without a password.

This only works when you are authorised to open the file — the tool needs the password to decrypt it, so it never bypasses security.

Adding password protection

To keep a sensitive document safe before sending, add strong encryption:

  1. Upload your PDF. Open the tool and add the file.
  2. Set a password. Choose a strong, unique password and confirm it.
  3. Download the protected PDF. The file is encrypted with strong 256-bit AES protection.

Security tip: share the password separately from the file — never in the same email or message. If the file leaks, the password is your last line of defence.

Only unlock what you own

Password removal only works when you know the password, which means you are the owner or have permission. The tools never break, crack or bypass encryption — they simply use the password you provide to decrypt the file. Always respect the rights of the document owner.

Frequently asked questions

Can I unlock a PDF if I forgot the password?

If you set the password yourself and remember it, you can remove it. The tool cannot decrypt a file without the correct password, and it never cracks passwords.

What encryption is used when protecting a PDF?

The protect feature applies strong 256-bit AES encryption, the same standard used by modern security tools.

Will password protection work on all devices?

Yes. PDF readers on every platform prompt for the password and open the file once it is entered correctly.

Is my PDF uploaded to a server?

No. Unlocking and protecting run entirely in your browser, so your document never leaves your device.
